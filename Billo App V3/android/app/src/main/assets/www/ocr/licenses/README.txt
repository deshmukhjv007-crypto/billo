Billo bundles the following open-source components for on-device bill OCR
(used with no network, no key, no account). All are Apache-2.0 licensed:
free to use commercially, no royalties, no revenue share, no per-use fees.

1. tesseract.js v6        (https://github.com/naptha/tesseract.js)        Apache-2.0
2. tesseract.js-core v6   (https://github.com/naptha/tesseract.js-core)   Apache-2.0  (WASM OCR core)
3. tessdata eng.traineddata (https://github.com/tesseract-ocr/tessdata)   Apache-2.0  (English language model)

Apache-2.0 only asks that the license text be kept with the software
(done here) — and permits modification and commercial use.
