# billo

billo expense tracking app

## What's in this repo

| Folder | What it is |
|---|---|
| `Billo App V3/` | Billo — group-trip expense tracker: receipts in, math out. Self-contained PWA (`app/`) + Android WebView shell with Play Billing (`android/`) + Play Store kit (`playstore/`). Tests: `node "Billo App V3/test/logic_test.js"` |
| `myna/` | Myna — real-time AI interview coach: live transcription, question detection, answers in your voice, debrief analytics. Zero dependencies. `cd myna && npm start` |
| `portfolio/` | Jayesh Deshmukh — portfolio & résumé: a one-pager with a particle field that inks itself into procedural drawings, a live-tunable **grain engine**, and a **zero-dependency résumé PDF engine** that generates the downloadable CV (plus an ATS-safe `.txt`) from a single data file. Zero dependencies. `cd portfolio && npm run build && npm start && npm test` |
